## The task
Two more capture layers for Dump, both optional, each behind a flag, each self-disabling with a note in Hook Status
when the runtime does not look as expected, zero effect on execution:

1. Full stage-level log of the last few hundred stages, taken from the runtime's own logging path while the
   database stays on Errors Only. Written as a section of incident.txt and a JSON array, same columns as a
   Complete session log export. Parameters masked for IBAN / CNP / card numbers.
2. The chain process page -> sub-page -> object action -> stage at the moment of failure, with every data item of
   every page in that chain and its current value, found by Radar itself so the Data Items input becomes optional.

First deliverable is a discovery run on the bank machine, since the class layout of Blue Prism 7.2.1 is only knowable there:
an action on the probe object that writes one text report of what the runtime exposes to a code stage, metadata
only, nothing called or changed. Vlad runs it, photographs or copies the report, and the two layers are written
against what it shows. Known fixed points: code stage frames read <ObjectClass>.Run_<Stage>, under
BluePrism.AutomateProcessCore.Stages.CodeStage.Execute, under Stages.ActionStage.Execute.
