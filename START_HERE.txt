GK REVOKE ON BLUE PRISM - START HERE
====================================

What this is
  The five GK Revoke bots (Master, Alice Maker, Alice Checker, BlueSpace Maker,
  BlueSpace Checker) rebuilt in Blue Prism. Tested end to end on UAT.
  Nothing gets installed. Blue Prism, Edge, Word and the trackers you already
  have are all it needs.

What is in this folder
  xml\        the 12 files to import (7 objects, 5 processes)
  config\     the 5 bot INI files: your original ones, plus the few XPath
              changes we made (listed in config\CHANGES.md). The secret values
              were replaced by {{TOKENS}} for the upload; step 2 puts them back.
  docs\       GUIDE.md = the full reference, if you ever need detail

Do the steps in this order. Each file is short.
  1 - Backup first.txt
  2 - Put the configs in place.txt
  3 - Make the environment variables.txt
  4 - Credentials and work queues.txt
  5 - Import the XML.txt
  6 - Check the machine and ServiceNow.txt
  7 - Get it running.txt
  8 - When it stops.txt
  9 - Changing settings later.txt

After it runs
  10 - Running it day to day.txt
  11 - Debugging step by step.txt
  12 - Turning a Python bot into Blue Prism.txt
  docs\DEV_PROMPT_python_to_bp.md = the prompt to give your AI for the next bot

Two rules that save the most time
  - Stop the Python bots before the Blue Prism ones run. Both use the same
    trackers and the same tickets.
  - Close every tracker in Excel while a bot runs. An open file makes the
    bot fail when it writes.
